Follow-up to the planted-letter post: I fine-tuned ink_9um (no labels, self-distillation) so that it calls depth-shuffled input "no ink". It learned that completely (0.0000 confident ink on shuffled input, control 0.0324 to 0.1783), and real-label AUC on the same four eligible-type crops did not move (median -0.0047, pre-registered verdict NULL). So the stronger response to depth-shuffled ink is not what holds the model back on these scans. The same fine-tune also responds less to the planted letters (stroke AUC down on 3 of 4 crops) while real-label AUC holds, so part of what makes planted ink visible is a depth cue that real ink does not need. Details and code: https://github.com/AndreasHad04/villa-apple-silicon#does-teaching-ink_9um-to-ignore-depth-shuffled-input-help-it-read-the-eligible-scans
